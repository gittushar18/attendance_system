# FaceTrack Pro

FaceTrack Pro is a smart attendance management system that uses facial recognition to automatically identify students and record their attendance. It is built using Python, OpenCV, Flask, and face recognition technology.

## Features

- Face recognition-based attendance
- Automatic student identification
- Attendance recording and management
- Simple web-based interface
- Reduces manual attendance work
- Fast and efficient recognition

## Technologies Used

- Python
- Flask
- OpenCV
- Face Recognition
- NumPy
- Pandas

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run the Project

Run the main application using:

python flask_app.py

## Purpose

This project provides a simple and efficient digital solution for managing student attendance using AI-based facial recognition.
